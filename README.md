# Tetris Java Edition

Java Swing을 사용하여 개발된 클래식 테트리스 게임입니다.<br>
기본적인 테트리스 메커니즘에 충실하면서도 콤보 시스템, T-스핀(회전 보정), 디버깅 모드, 사용자 편의 기능(키 설정 변경) 등이 추가된 버전입니다.

## 주요 기능

* **향상된 게임 플레이**:
    * **콤보 시스템**: 연속으로 줄을 제거할수록 기하급수적으로 점수가 증가합니다.
      > 공식:`(이전 콤보 값 + 현재 삭제된 행의 개수 + 1) * 삭제된 행 * 100`
    * **T-스핀 및 회전 보정**: 벽이나 바닥 근처에서도 블록이 자연스럽게 회전할 수 있도록 SRS와 유사한 킥(Kick) 로직을 구현했습니다.
    * **홀드 & 고스트**: 전략적인 플레이를 위한 블록 저장 및 낙하 위치 미리보기 기능을 제공합니다.
* **사용자 경험 (UX)**:
    * **UI 한글화**: 게임 내 모든 메뉴와 UI가 한국어로 제공됩니다.
    * **이펙트**: 블록을 바닥에 떨어뜨릴 때 화면이 흔들리는 타격감 효과가 적용되었습니다.
    * **조작 키 변경**: 방향키 모드와 WASD 모드를 실시간으로 전환할 수 있습니다.
* **개발자 도구**:
    * **치트/디버그 모드**: 특정 커맨드를 입력하여 블록 생성 확률(가중치)을 임의로 조절할 수 있는 설정 메뉴가 해금됩니다.
    * **크레딧 페이지**: 개발자 및 라이선스 정보를 확인할 수 있습니다.

## 클래스 및 메소드 구조

이 프로젝트의 핵심 로직은 `TetrisMain.java`와 `TetrisBoard.java`로 구성되어 있습니다.

### 1. `TetrisMain.java`
프로그램의 진입점이자 화면 전환(CardLayout)을 관리하는 메인 프레임 클래스입니다.

#### 필드
* `cardLayout`: 화면 전환을 담당하는 레이아웃 매니저
* `mainPanel`: 모든 패널(메뉴, 게임, 설정 등)을 담는 컨테이너
* `gameBoard`: 실제 게임이 진행되는 `TetrisBoard` 객체
* `blockWeights`: 각 블록(7종)의 생성 가중치를 저장하는 정적 배열 (기본값: 10)
* `useWasd`: WASD 키 사용 여부를 결정하는 정적 플래그

####  주요 메소드
* `TetrisMain()`: 윈도우 초기화 및 패널들을 `mainPanel`에 등록
* `showGame()`: 게임 화면으로 전환 및 게임 시작 (`gameBoard.start()`)
* `showMenu()`: 메인 메뉴 화면으로 전환
* `showGameOver(int score)`: 게임 오버 화면으로 전환 및 점수 전달
* `showCheat()`: 블록 확률 조작 패널로 전환
* `showCredit()`: 크레딧 화면으로 전환

#### 내부 클래스
* `MainMenuPanel`: 게임 시작, 설정 진입 등을 담당하는 시작 화면 (코나미 커맨드 입력 시 디버그 버튼 해금)
* `CreditPanel`: 개발자 정보 및 라이선스 명시
* `CheatPanel`: JSlider를 이용해 블록별 등장 확률(Weight)을 실시간으로 조절
* `GameOverPanel`: 게임 종료 후 점수 표시 및 메뉴 복귀

---

### 2. `TetrisBoard.java`
테트리스의 핵심 로직, 렌더링, 키 입력 처리를 담당하는 클래스입니다.

#### 필드
* **게임 상태**
    * `board`: 20x10 격자의 블록 상태를 저장하는 2차원 배열
    * `isPaused`, `isGameOver`: 게임 진행 상태 플래그
    * `curPiece`, `nextPiece`, `holdPiece`: 현재/다음/홀드 블록 객체
* **점수 및 콤보**
    * `score`: 현재 점수
    * `combo`: 현재 연속 콤보 횟수
    * `lastMoveCleared`: 이전 턴에 줄 삭제가 발생했는지 여부 (콤보 계산용 핵심 필드)
* **이펙트**
    * `shakeX`, `shakeY`: 하드 드롭 시 화면 흔들림 좌표

#### 주요 메소드
* `start()`: 게임 변수(점수, 콤보, 보드 등)를 초기화하고 타이머를 시작
* `tryKickRotate()`: 블록 회전 시도 시 벽이나 다른 블록에 막힐 경우, 좌우/상하/대각선으로 위치를 보정하여 회전을 성공시키는 메소드 (T-스핀 구현)
* `pieceDropped()`: 블록이 바닥에 고정될 때 호출. 줄 삭제 여부를 판단하고 **콤보 점수 산식**을 적용
* `removeFullLines()`: 꽉 찬 줄을 찾아 삭제하고 윗줄을 아래로 당김
* `tryMove(Shape, x, y)`: 블록이 해당 위치로 이동 가능한지 충돌 검사
* `drawUI(Graphics2D)`: 점수, 콤보, 다음 블록 등 HUD를 렌더링
* `dropDown()`: 하드 드롭 구현 (바닥에 닿을 때까지 즉시 이동 + 흔들림 효과)
